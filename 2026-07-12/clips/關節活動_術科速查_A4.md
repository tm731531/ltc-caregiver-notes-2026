# 關節活動 術科速查 · A4 一頁

> 術科 BA11 肢體關節活動｜三考項:上肢／下肢／轉移位｜考試 8/1
> 來源:課堂錄影 `youtu.be/eKB6-123NaA`(16:08)

## 🧠 三句話記全部
1. **手心朝個案自己,固定近端、動遠端**
2. **遇阻力就停,撐 5–10 秒,慢慢拉、不要一次到底**
3. **方向都是「上下 → 內外 → 畫圈」;手由肩→肘→腕→指,腳由髖膝→踝→趾**

---

## ✋ 手(上肢)— 一手扶手腕、一手扶手肘,手心朝個案自己

| 部位 | 動作 |
|---|---|
| **肩 ① 向上** | 手臂往上舉,貼向耳朵/床,遇阻力停 |
| **肩 ② 向外** | 手心向外,伸直往外開再往上貼耳朵 |
| **肩 ③ 內外轉** | 肩90°、肘90°;**大拇指朝下=外轉,小拇指朝下=內轉**(內轉較緊,撐一下) |
| **肩 ④ 畫圈** | 順時鐘、逆時鐘各畫 |
| **手肘** | 彎伸(摸肩膀、摸床)＋「開門」(上臂貼身側,前臂轉上轉下) |
| **手腕** | 上下、左右、畫圈 |
| **手指** | 一節一節彎、伸(握拳 → 張開) |

## 🦵 腳(下肢)— 扶腳跟＋膝蓋,髖和膝一起動(不單做膝蓋)

| 部位 | 動作 |
|---|---|
| **髖+膝 ① 彎** | 大腿抬起,和身體成一直線(**不要往外歪**) |
| **髖+膝 ② 外展** | 往外張開,**不要無限往外拉** |
| **髖+膝 ③ 內外轉** | 膝90°,固定大腿、動小腿(像翹腳)往內往外 |
| **髖+膝 ④ 畫圈** | 小圈到大圈,順/逆時鐘 |
| **腳踝** | 向上下、向內外、畫圈 |
| **腳趾** | 一隻一隻向上、向下 |
| **拉小腿/跟腱** | 🔑 前臂頂腳掌,**用身體重量往斜上壓**帶動(省力、護腰) |

## 🔄 身體(翻身 → 坐起)

- **翻身**:扶**髖關節和肩膀**(先把下面那隻腳屈膝踩住/交叉)→ 喊「1、2、3」翻過來 → 提醒個案「**都不要出力**」由照顧者帶
- **坐起**:翻成側臥後 → 一手放臀部、一手穿過肩背 → 順勢帶起坐正 → 腳放下、放平

---
**每關節每次約 10–20 下、每天 1–2 次。動作順序沒有硬性規定,由大關節做到小關節即可。**
