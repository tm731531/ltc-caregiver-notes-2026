## 📌 貫穿全天的照顧原則（開場概論）

- **促進舒適的四要素**：安全感、舒適感、關懷/愛心/同情心。
  - **安全感＝具體行動**：動手前先自我介紹＋**每個步驟都事先告知**（「我是吳老師，來照顧你兩小時，等一下要…」）。
  - **舒適感＝具體行動**：事前問「想要我怎麼幫你做？可以嗎？」→ 事後問「這樣可以嗎？」。
- **執行任何身體照顧前，必先「經個案同意」並取得配合**；紀錄要寫明「經個案同意」。口訣：**照顧人員永遠做老二，不能當老大**（以案主意願為主）。
- **身體力學（保護照服員自己）**：
  - **用膝蓋決定高度，上半身不彎腰**；轉向**用腳轉**、不可轉腰（會閃到腰）。
  - 現行規定**不宜依賴護腰/護腕**（貼護腰腹肌就不出力、綁護腕代表手腕被過度使用）→ 從姿勢根本避免彎腰。

## 一、個人衛生維持整潔（前導）

**四大注意事項（高頻考點）**
1. **評估肢體功能，鼓勵可動肢體清潔**：好手讓他自己洗，患側（如中風手）由照顧者扶著協助，盡量讓他運動、有機會照顧自己。
2. **評估身體清潔習慣，盡量配合**：問想何時洗澡、可商量時間；長期不洗會臭 → 自尊受損、社交退縮。
3. **評估文化/宗教影響並尊重**：例「坐月子不洗頭、不碰生水」；宗教習俗放心裡、不妄下評語。
4. **配合治療與作息時間**：例復健會流汗，應**復健後再洗澡**。

**身體清潔的生理益處**：促進血液循環、清潔、刺激知覺、維持關節活動度（久不動的關節會僵縮攣縮）。
**評估健康觀察點**：**四肢末端（手腳）溫度**（暖＝循環/營養好，冰冷＝照顧不足）、臉色、嘴唇、眼神、活動力、皮膚。
**評估情緒**：聽到「讓他死死的好了」這類話要**非常認真聽**，是求救訊號。

## 二、擺位、翻身與拍背實務

**姿勢與力學原理**
- **姿勢三要素**：骨骼、肌肉、關節（三者協調）。良好姿勢＝肌肉群與身體部位處於良好排列。
- **疲勞原理**：**小肌肉比大肌肉易疲勞、小關節比大關節易疲勞** → 所以拍背要用**大關節（肩/肘）力量**。

**翻身擺位**
- **每 2 小時翻身一次**（書上標準），但**真正原則是看皮膚**：翻身時看受壓皮膚有無變紅，變紅且恢復慢就縮短為 **1.5 小時**；無變化可延長。（不可機械式延到 3 小時而不觀察 → 見待查核 🟠）
- **正常解剖位置**：平躺/側躺身體呈一直線；側臥「**下彎上直**」（下腳彎、上半身直）。**手要適當彎曲**、不可伸直。
- **枕頭支托**：側臥前後各壓一枕頭；**一張床至少 4 顆枕頭**支托，身體不懸空。
- **側臥重點**：被壓在下方的**手臂一定要拉出來**，否則全身重量壓住會廢掉。
- 翻身後注意隱私、蓋被、檢查各部位載重負擔。

**背部護理／叩背（拍背）排痰**
- 目的：刺激**腦內啡**分泌、緩解疼痛、放鬆肌肉、促進血液循環、觀察皮膚。手法：按撫法、揉捏法、叩擊；本次教**叩背排痰**。
- **肺葉數**：**右 3 葉、左 2 葉**；**肺尖在鎖骨上方**（約一橫指）。
- **只拍左右兩側肺區，脊椎中線不可拍**。**支氣管分叉**約在第二顆釦子／胸骨往下約 5 公分。
- **手勢與力量**：手掌拱成**空心掌（杯狀）**，**手腕不動、用大關節力量帶動**。震到肺排痰但病人的肉不會痛；**若拍到肉會痛就是拍錯**（手腕出力或掌沒拱好）。
- **方向**：**痰在上往下拍、痰在下往上拍**（朝主支氣管引流排出）。

## 三、儀容整理實務（穿脫衣、盥洗、指趾甲）

**穿脫衣物（考試重點口訣）**
- **兩手都不能動（躺著）**：先穿**遠端**再近端；先脫**近端**再遠端。
- **一手不能動（中風）/坐輪椅**：**先穿患側（壞邊）、先脫健側（好邊）**。
- 左手無力者褲子選**鬆緊帶**（免扣）。

**盥洗/洗臉**：順序 **眼→耳/鼻→全臉→頸部→梳頭**；眼睛由內眥往外擦；鼻孔用棉枝從鼻翼軟處轉一圈；耳朵往後拉看耳垢，看不到不硬清；老人頸紋要撥開檢查。

**指（趾）甲照顧**
- **手指甲修圓弧形、腳趾甲修平形**，防**嵌甲**（趾甲剪弧形會腫、嵌進肉）。
- 修剪前浸泡 **41～43℃ 溫水 15～20 分鐘**軟化（先泡再剪，輪流泡另一手/腳）。
- 修剪時要有充分光線；**糖尿病/循環障礙者**避免修剪不當造成傷口。

## 四、床上洗頭與擦澡實務

**床上洗頭步驟（技術）**
1. 告知個案、**洗手**、備物。
2. 測水溫：**先放冷水再加熱水**，用手測（投影片 **41～43℃**）。
3. 放洗頭槽，槽下先鋪**塑膠布＋大毛巾**防床濕。
4. 個案**頭超出床沿約 10 cm**，排水端下方**接水桶**。
5. 先淋少量水試溫、問感受 → 打濕全頭。
6. **先檢查頭皮**有無頭皮屑/受傷/腫塊 → 用**指腹**（不可用指甲）洗。
7. 水勿流入耳朵/眼睛。
8. 沖淨後**檢查後腦勺有無殘留泡沫**；要潤髮則潤後再沖；擦乾、吹乾、梳好。
- 洗頭頻率**每週 2～3 次**；心臟病/氣喘/呼吸不順採**半坐臥**。
- 投影片另列：可用潤絲精、**檸檬汁或醋**促進柔軟；可用**酒精**擦除頭髮血漬（**考試以投影片＝酒精為準**，講師個人反對但那是他個人意見 → 見待查核 🟠）。

**毛髮/皮膚護理補充**
- 掉髮一天約 **60～100 根**內正常；梳頭前頭下墊毛巾接落髮；梳長髮要**分層**梳、不可從頭直接梳到尾。
- 昏迷/長髮個案**不隨意剪髮**（尊重、善終考量）。
- **皮膚分層**：表皮→真皮→皮下組織→肌肉層。**皮膚功能**：保護、調節體溫、感覺、分泌排泄、吸收。

**床上擦澡（技術）**
- 三種清潔法：**淋浴、盆浴、床上擦澡**（床上擦澡對象＝活動受限/身體虛弱/意識不清無法下床；依協助程度分完全/部分/自行）。
- **擦澡範圍順序**：**前胸腹 → 後背臀部 → 雙上肢/手掌 → 雙下肢/腳掌**；毛巾**旋轉洗**（不可來回抹）；皺褶處要擦乾；女性乳房撥開洗下方皺褶。
- 洗手用**毛巾包裹法**包住手臂、每根手指都洗，一定要洗到末端並檢查末端。
- **選毛巾考點**：用**不同大小＋不同顏色**毛巾區分洗臉/洗身體/洗屁股/洗耳朵（避免用洗屁股的毛巾洗臉、方便交接辨識）。

## 五、會陰沖洗與清潔實務

**構造**
- **男性會陰部**：陰莖、陰囊、龜頭、包皮。
- **女性會陰部**：陰阜、大陰唇、小陰唇、陰蒂、尿道口、陰道口、會陰。
- 「會陰」＝陰道口/尿道口與肛門之間那塊肉（產科剪會陰即此）。

**需做會陰沖洗的對象**：留置導尿者、長期臥床、生殖泌尿道發炎、大小便失禁、肛門/會陰手術者、產後婦女。

**注意事項**
- 注意隱密（關門窗、圍簾）＋保暖披覆；**有傷口/留置導尿管 → 外科無菌技術**（棉枝須消毒、在效期內）。
- 水溫 **41～43℃**、每次沖洗量 **300～500 mL**（投影片；講師口述 300 c.c.，以投影片為準）。
- 清潔溶液：**開水（冷熱開水兌成，非自來水）**、生理食鹽水、水溶性優碘。
- 姿勢：**屈膝仰臥式**；壺嘴**朝向床尾**（才不會沖進體內）。

**女性沖洗法（用清水，不用泡沫）**
- 因**女性尿道短**，泡沫易跑進去刺激 → **只用清水**。用 **5 支棉枝**，一面沖一面洗。
- **清洗順序（5 步，國家技術考重點）**：
  **尿道口 → 遠側小陰唇 → 近側小陰唇 → 遠側大陰唇 → 近側大陰唇**（由上往下、**不可回沖**）。
- 再用**乾棉枝依同序擦乾**，衛生紙擦大腿內側水漬。「遠側」＝離操作者較遠那邊。

**男性沖洗法（可用肥皂/香皂）**
- 先看分泌物；棉枝沾香皂，**把包皮往後推露出龜頭**，先洗龜頭（用棉枝）。
- 其餘部位**用毛巾**：**陰莖 → 陰囊 → 肛門**（陰莖細分 上→左→右→下，左陰囊→右陰囊→肛門），全程肥皂水，再沖淨。
- 最後換**乾毛巾**依同序擦乾。

## 六、技術示範：洗手七步驟 & 口腔清潔

### 洗手七步驟（濕洗手）
- **前置**：指甲剪短、除飾品、捲袖至**肘上約 2 吋（5 cm）以上**。
- **口訣：內、外、夾、弓、大、立、腕**
  | 步驟 | 部位 |
  |------|------|
  | 內 | 手掌對手掌 |
  | 外 | 手掌搓手背（兩手交換）|
  | 夾 | 十指交叉搓指縫 |
  | 弓 | 指背互扣搓指節 |
  | 大 | 包握大拇指旋轉（約 5 下）|
  | 立 | 指尖立在掌心搓（約 5 下）|
  | 腕 | 搓手腕 |
- **收尾**：開水沖淨 → **捧水沖洗水龍頭開關**（避免關水時手再被汙染，易考「為什麼捧水」）→ 關水 → 甩手 → 擦手紙擦乾。

### 口腔清潔照顧
- **時機**：吃完飯約 **5 分鐘**內清潔。**目的**：促進唾液分泌、減少細菌、維持舒適與食慾、早期發現口腔問題。
- **牙刷規格**：刷毛 **2～3 排**、每排約 **6～7 束**；刷毛外翻即換；刷後保持乾燥。漱口用一般開水即可。
- **假牙**：屬活動義齒，**睡前取下清潔、晨起裝回**；**一週不戴就裝不上**（口腔會變）。
- **特別口腔護理**：口腔**有傷口者每 2 小時清潔一次**；張口呼吸/病重者用**凡士林**護唇、**濕紗布**擦拭。
- **背式刷牙法**（幫人刷省力）：從一側兩三顆牙、**45 度橫刷**，外側→內側→咬合面→下牙；此法不用牙膏。刷後用**潔牙棒**沿牙齦繞一圈、再刷舌頭。

### 甘油球灌腸（今天臨時加回的技術）
- **便秘判準**：超過**第 4 天**沒大便才需協助（正常：三天一次～一天三次）。
- 步驟：**定點按摩腹部（右→橫→左，順時針/升→橫→降結腸）→ 側身 → 甘油球沾潤滑液 → 撥開肛門塞入**。
- **關鍵手法**：塞入後**不可馬上壓，先停 3～4 秒** → 慢推、推時叫個案**大力吸氣** → 推完**不可馬上拔** → 衛生紙慢慢滑下、不可用力。
- 留置 **30 分鐘**溶解後再排出。
